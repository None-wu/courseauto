# 真实环境部署指南

从零到在**真实学习通**上跑起来，两条路选一条。全程不需要改代码。

---

## 方案 0:发给客户(单文件 exe,最省事)

如果这份东西是给别人用的,别让对方装 Node、敲命令:

```bash
npm run pack        # 打包机需要 Node + bun;客户机什么都不用装
```

产物在 `dist/`:

| 文件 | 说明 |
|------|------|
| `刷课助手-vX.Y.Z.exe` | 单文件(约 90 MB),双击即起服务并打开安装向导,内置两个脚本 + 网页 AI 中转 |
| `使用说明.txt` | 给客户看的图文步骤 + 常见问题 |
| `刷课助手-vX.Y.Z-win64.zip` | 上面两个的压缩包(约 30 MB),微信/邮件传输更稳 |

客户侧只需要三步:双击 exe → 在向导里装油猴 → 点一下装脚本,然后直接点向导第 4 步的站点入口进课程页。**exe 窗口要一直开着**,
脚本用「网页 AI」通道答题时靠它转发(关掉窗口只是退出中转,已装的脚本照常存在)。

> 打包细节见 `tools/pack.mjs`:先把 `src/` 构建成两个 `.user.js`,再把它们 + 安装页内联进
> `build/assets.gen.mjs`,最后用 `bun build --compile` 编成单文件。客户版**不含**模拟页面与测试代码。

## 0. 前置条件

| 项目 | 要求 |

## 方案 A：本地一键安装（推荐，仓库没发布也能用）

```bash
cd courseauto
npm run setup        # 检测本机浏览器 → 启动本地安装页 → 自动打开浏览器
```

打开后是一个四步向导（`http://127.0.0.1:8790/setup`）：

1. **装脚本管理器** —— 页面会读取本机浏览器扩展目录，判断你是否已装 Tampermonkey/篡改猴。
   - 显示 `✗ 待安装` → 点「去商店安装 Tampermonkey」，装完回来自动变 `✓ 已装好`（每 3 秒重检）。
   - **为什么不能全自动**：Chrome/Edge 只允许从官方商店安装扩展，任何程序都无法静默写入，这是浏览器安全策略。
2. **装入脚本** —— 点「安装「刷课助手」」，油猴会拦截并弹出安装确认页，点「安装」。
   - 用网页 AI 答题的话，把「网页 AI 桥」也装上。
3. **开始刷课** —— 直接点「学习通 / 智慧树 / 雨课堂」三个入口之一，登录后进课程页；右下角出现「刷课助手」面板即代表脚本已生效（首次用先在 ⚙ 里填 AI Key 或选「网页 AI」）。

> 只装了脚本、想跳过向导也可以：`npm run detect` 只做检测并打印结果，`npm run mock` 只起本地模拟站点。

## 方案 B：线上安装（推送到 GitHub 后）

仓库推送到 `main` 后，脚本可通过 jsDelivr 直装：

```
https://cdn.jsdelivr.net/gh/None-wu/courseauto@main/userscripts/courseauto.user.js
```

- 浏览器打开这个链接，油猴会弹出安装页；点「安装」。
- 首次推送后 CDN 需要几分钟同步，打不开就等一会儿。
- 更新走同一路径，`version.json` 是版本标记（见下节）。

网页 AI 桥的线上地址：

```
https://cdn.jsdelivr.net/gh/None-wu/courseauto@main/userscripts/courseauto-webai-bridge.user.js
```

### 版本与自动更新

- 发版时必须**同时**改两处，否则更新检测不生效或误判：
  - `userscripts/courseauto.user.js` 头部 `@version`
  - `version.json` 的 `{"v": "x.y.z"}`
- 脚本逻辑：每 5 分钟检查一次（仅空闲时），**只有远端版本严格高于本地**才刷新页面；刷新后 6 小时内不再重试，避免「更新失败→反复刷新」的死循环。
- 油猴自身的「脚本更新间隔」建议设为最短，它负责真正下载新版。

## 真实站点验证清单

1. 打开 https://i.chaoxing.com ，手机号 + 密码登录
2. 「我学的课」→ 选一门课 → 进入章节学习页（网址含 `/mycourse/studentstudy`）
3. 右下角出现黑白面板，标题栏状态胶囊显示「工作中」= 成功
4. 脚本会把旧版 `?mooc2=1` 之外的老页面自动切到新版，无需手动改地址
5. 面板能拖动；点 ⚙ 打开设置

> 如果网址是 `mooc1.chaoxing.com` / `mooc2-ans.chaoxing.com` / 学校自有域名，都在 `@match *://*.chaoxing.com/*` 覆盖范围内；学校用非 chaoxing 域名的定制版则需要自行加一条 `@match`。

## 答题通道三选一

| 通道 | 配置 | 适用 |
|------|------|------|
| 网页 AI（免 Key） | ⚙ → 勾选「网页 AI 答题」→ 点「打开并连接网页 AI」→ 在弹窗里登录 | 不想花钱；需同时装桥脚本 |
| API（最稳） | ⚙ → 勾选「启用 AI 答题」→ 选平台 → 填 Key → 保存 | 长期使用；见 [get-api-key.md](get-api-key.md) |
| 题库 | 默认关闭 | 免费题库多已停服，不建议依赖 |

优先级：**网页 AI > API > 题库**。任何一路拿到答案就停止。

## 故障排查

| 现象 | 原因 / 处理 |
|------|-------------|
| 课程页没有面板 | ① `edge://extensions` / `chrome://extensions` → Tampermonkey「详细信息」→ 打开「**允许用户脚本**」（新版浏览器默认关闭，关着时脚本显示"已启用"却不执行；油猴弹窗顶部出现黑条提示、脚本名变灰就是它）→ ② 油猴里脚本开关是否开启 → ③ F5 刷新。向导第 2 步会自动读出这个开关的状态 |
| 向导第 1 步一直显示未安装 | 扩展装在了另一个浏览器；或用了 Firefox/360 等未纳入扫描的浏览器。按提示去商店装，然后点「重新检测」 |
| 向导第 2 步显示「读不到开关状态」 | 浏览器版本较旧，没有「允许用户脚本」开关（旧版本一般默认允许）。直接点第 4 步的站点入口进课程页看面板即可 |
| 点「安装脚本」没反应 | 油猴没装好，或脚本装在了别的浏览器；先回到第 1 步 |
| 面板出现但不动 | 浏览器禁止自动有声播放 → 页面任意位置点一下鼠标（脚本已静音）；或面板 ▶ 处于暂停态 |
| 答题提示「未查到答案」 | 网页 AI 弹窗被拦截（需点按钮触发）/ API Key 无效或余额为 0 / 全局代理导致境内接口失败 |
| 章节测验完全没反应 | v1.3.1 已支持「测验直嵌 `/mooc2/work/dowork`」结构。若仍无反应，看面板日志：出现「⚠ 未找到测验题目」会紧跟一行 `🔍 侦察(测验)` 列出所有 iframe 的 src，把这一行发出来即可定位 |
| 更新后版本没变 | `@version` 与 `version.json` 没同步改；或油猴未通过 CDN 拉到新文件；本地安装则重新走一次向导 |
| 视频不结束、卡住 | 已知边界：个别视频源 403 无 `ended` 事件。刷新页面重试；仍不行请在设置里降低倍速 |
