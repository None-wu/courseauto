# extras/ · 非程序文件

程序本体只有 `src/` `local/` `tools/` `userscripts/`；这里放的是**跑测试、写文档、留备份**才用得上的东西，
客户版 exe 完全不含本目录内容。

| 目录 | 内容 | 怎么用 |
|------|------|--------|
| `tests/` | 端到端沙箱：无头浏览器注入 GM 垫片跑通三平台 + 各类断言（含判断题/多选/新版结构/正确率阈值） | `npm run test:all`（根目录执行） |
| `tests/out/` | 测试截图与日志（自动生成，可删） | 排查失败用 |
| `mock/` | 模拟页面：章节、卡片、视频、音频、文档、测验内外层、AI 对话页 | 由 `npm run mock` 提供服务 |
| `probe/` | 真实站点自检失败时回传的页面结构快照 | 适配新改版时据此写选择器 |
| `docs/` | 模块文档：自动答题、练题自测、API Key、部署指南、多平台规划 | 直接读 |
| `backup/` | 历史版本脚本备份 | 回滚用 |
| `自检-答题记录检查.js` | 粘贴到学习通控制台，检查答题记录是否真的写进去了 | 手动自检 |

> 测试与模拟页面之间的相对路径已按 `extras/` 调整：测试脚本引用 `../../local/server.mjs`，
> 开发服务器从 `../extras/mock/` 取页面，`extras/probe/` 收采集文件。
