# 刷课助手(学习通 / 智慧树 / 雨课堂)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Userscript](https://img.shields.io/badge/userscript-Tampermonkey-blue.svg)](userscripts/courseauto.user.js)
[![Release](https://img.shields.io/github/v/release/None-wu/courseauto?label=release)](https://github.com/None-wu/courseauto/releases/latest)
[![CI](https://github.com/None-wu/courseauto/actions/workflows/ci.yml/badge.svg)](https://github.com/None-wu/courseauto/actions/workflows/ci.yml)

> 一个油猴(Tampermonkey)脚本,自动完成网课课程任务点。
> **v1.3.0 起支持三个平台**:学习通(超星)、智慧树(知到)、雨课堂。
> **零基础可用**:不用写一行代码,装两个东西,填一个 Key,打开课程页就自动干活。

> **来源**:本项目基于 [DaRin1403/xuexitong-autostudy](https://github.com/DaRin1403/xuexitong-autostudy)(MIT)二次开发,
> 沿用其 MIT 许可与原始版权声明;`.git` 历史中保留了原作者的全部提交记录。在此基础上重构了内核/适配器分层、
> 补齐了网页 AI 免 Key 答题、判断题与新版页面结构适配、本机安装向导与客户版打包。

## 🌐 多平台支持(v1.3.0)

| 平台 | 能力 | 状态 |
|------|------|------|
| 学习通(超星) | 视频/音频/文档/图片、弹题、章节测验自动答题、自动切章、作业页 | ✅ 完整(与 v1.2.0 相同) |
| 智慧树(知到) | 视频静音限速连播(≤1.5x,防时长不计)、目录树自动切节点、弹题自动作答 | ⚠ 实验版,测验/考试未实现 |
| 雨课堂 | 视频静音播放、**后台保活**(失焦不再暂停)、弹题作答、自动连播、验证码熔断 | ⚠ 实验版,习题/讨论未实现 |

- 架构:平台无关内核 + 每平台一个适配器(`src/core` + `src/adapters`),构建命令 `npm run build` 打成单个 `.user.js`
- 每个适配器带**自检**:平台改版导致选择器失配时,面板会明确报错(而不是静默没反应),并自动把页面结构发回本机采集端(`extras/probe/`),便于快速修复
- 智慧树/雨课堂的真实页面结构仍可能与我按社区公开资料写的选择器有出入:先跑 `npm run mock` + 在真实页面刷新(自检失败会自动采集),把 `extras/probe/*.json` 发我即可修

## ⚠️ 使用前必读(风险提示)

- 学习通平台已声明使用 **AI、大数据技术监控**"刷课"行为,并可能**通报学生所在高校**;一经查实,学校可给予警告直至开除学籍等处分。
- 脚本保留了完整的一套**拟人化配置**(倍速上限、随机延迟、故意答错率、到点自动关闭),但为了"能跑完"默认是最快的那档:2x 倍速、零延迟、不限时。**风险自担**:要稳就把 ⚙ 里的倍速调回 1x、设一个到点关闭时间、把故意答错率调到 5~8%。
- 本项目仅供个人学习辅助与技术研究,使用产生的一切后果由使用者自行承担。

## 📁 项目结构

```
courseauto/
├── userscripts/                  # 发布物:两个油猴脚本(由 npm run build 生成,勿手改)
│   ├── courseauto.user.js               # 主脚本(刷课/答题/面板)
│   └── courseauto-webai-bridge.user.js  # 网页 AI 桥(免 Key 答题)
├── src/                          # 源码:平台无关内核 + 三平台适配器
│   ├── 00-meta.txt                      # 元数据(@version 是版本号唯一源头)
│   ├── core/                            # 面板/配置/AI 通道/字体解密/更新检测/主流程
│   └── adapters/                        # chaoxing.js / zhihuishu.js / yuketang.js
├── local/                        # 本机服务:安装向导 + 网页 AI 中转
│   ├── core.mjs                         # 安装/中转/采集/环境检测(客户版与开发版共用)
│   ├── app.mjs                          # 【客户版入口】打包成 exe 的那份
│   ├── setup.mjs                        # npm run setup:检测→起服务→打开向导
│   ├── server.mjs                       # 开发用:core + 模拟学习通页面 + 假 AI
│   ├── detect.mjs                       # 扫描浏览器扩展,判断油猴是否已装
│   ├── pages/setup.html                 # 四步安装向导(黑白,末尾直达三个刷课站点)
│   └── lib/gm-shim.js                   # GM API 垫片(无油猴时跑脚本用)
├── tools/                        # build.mjs(拼脚本) / pack.mjs(打 exe)
├── extras/                       # 非程序文件
│   ├── tests/                           # 端到端沙箱(无头浏览器 + 断言)
│   ├── mock/                            # 模拟页面:章节/视频/测验/新老版本结构
│   ├── docs/                            # 模块文档 + AI Key + 部署指南
│   ├── backup/                          # 历史版本脚本备份
```

## 🚀 快速开始

三种安装方式，任选其一。零基础推荐**方式 A**。

### 方式 A：本地一键安装（推荐）

```bash
cd courseauto
npm run setup
```

脚本会检测本机浏览器是否已装油猴，并自动打开安装向导 `http://127.0.0.1:8790/setup`：装扩展 → 一键装脚本 → 点站点入口直接开刷。**不用复制任何代码。**
（扩展本身只能从官方商店安装，这是浏览器安全策略，向导会给你直达入口。）

### 方式 B：线上直装（仓库已推送时）

装好油猴后，点这个链接，油猴会弹出安装页：

👉 **[点此一键安装](https://cdn.jsdelivr.net/gh/None-wu/courseauto@main/userscripts/courseauto.user.js)**

> 首次推送后 CDN 需几分钟同步；打不开就稍等重试。

**不想装油猴、或者要给同学用？** 直接下免安装版（Windows，双击即用，自带安装向导）：

👉 **[下载 courseauto-v1.5.2.exe](https://github.com/None-wu/courseauto/releases/latest)**（单文件，含网页 AI 中转；压缩包与使用说明在同一个 Release 里）

> **从旧版升级（v1.3.x → v1.4.0）**：这一版把项目改名为 **courseauto / 刷课助手**，脚本 `@name`、安装地址、
> 仓库地址全变了，油猴会把它当成一个新脚本。**先在油猴面板删掉旧的「网课助手」，再装新的**，
> 否则两个面板会同时跑；配置（AI Key、倍速等）需要在新面板 ⚙ 里重填一次。

### 方式 C：手动安装

油猴管理面板 → 左上角「**+**」新建脚本 → 清空编辑器 → 把 `userscripts/courseauto.user.js` 全文粘贴进去 → `Ctrl+S` 保存。

### 方式 D：打包成 exe 发给别人（客户零环境）

```bash
npm run pack        # 产物在 dist/:刷课助手-vX.Y.Z.exe + 使用说明.txt + win64.zip
```

得到的 exe **自带安装向导、两个脚本和网页 AI 中转**,对方不用装 Node、不用敲命令:
双击 → 浏览器自动打开向导 → 装油猴 → 点一下把脚本装进去。窗口保持开着即可,
脚本答题时靠它转发 AI 请求(关掉窗口只是退出中转,不影响已装的脚本)。

> 打包用 [bun](https://bun.sh) 的 `--compile`(单文件、内置运行时)。exe 约 95 MB,
> 压缩包里约 36 MB。首次运行若遇 Windows「已保护你的电脑」,点「更多信息 → 仍要运行」。

然后阅读 **[docs/部署-真实环境.md](extras/docs/部署-真实环境.md)** 完成 AI 配置与真实站点验证。

## 🧰 装油猴(Tampermonkey)与环境开关

油猴是浏览器的"脚本运行器",装一次永久使用。**Windows 和 Mac 操作一样**,选你正在用的浏览器:

<details>
<summary>🔵 Microsoft Edge(Windows 自带,推荐 Windows 用户)</summary>

1. 打开 Edge 应用商店搜索「**Tampermonkey**」(中文名"篡改猴"),点安装
2. 安装后,**Edge 设置里必须开启「允许用户脚本」**:
   - 地址栏输入 `edge://extensions` 回车
   - 找到 Tampermonkey → 点「详细信息」
   - 把「**允许用户脚本**」开关打开(不开脚本不会运行!)
</details>

<details>
<summary>🟢 Google Chrome(Windows / Mac 通用)</summary>

1. 打开 Chrome 网上应用店(需要能访问 Google),搜索「**Tampermonkey**」安装
2. 开启「允许用户脚本」:
   - 地址栏输入 `chrome://extensions` 回车
   - 找到 Tampermonkey → 点「详细信息」
   - 打开「**允许用户脚本**」开关
</details>

<details>
<summary>🧭 Safari(仅 Mac)</summary>

1. 打开 App Store,搜索「**Tampermonkey**」,安装(收费约 12 元)
2. 安装后打开 Safari 的「设置 → 扩展」,勾选启用 Tampermonkey
3. Safari 的油猴是独立 App,脚本安装流程与 Chrome/Edge 相同
</details>

> 💡 不确定装对没有?随便打开一个网页,点浏览器右上角的油猴图标,能弹出菜单就是装好了。

### 装完脚本后的 AI 配置(做题必需,2 分钟)

章节测验的自动答题靠大模型完成。**两种方式任选**:

- **网页 AI(免 Key)**:再装一个 `userscripts/courseauto-webai-bridge.user.js`,打开课程页 → 面板 ⚙ → 勾选「网页 AI 答题」→ 点「打开并连接网页 AI」→ 在弹出的 AI 网页里登录
- **API Key(最稳)**:⚙ → 勾选「启用 AI 答题」→ 选平台 → 填 `sk-` 开头的 Key → 保存
  - 推荐 **DeepSeek**(便宜、准);各平台注册地址/接口地址/模型名见 [📄 docs/get-api-key.md](extras/docs/get-api-key.md)

> Key 只保存在你自己的浏览器里,不会上传到任何地方。

## ❓ 常见问题(FAQ)

**Q: 打开课程页没有出现面板?**
A: 依次检查:① 油猴已安装且脚本开关开启;② 浏览器扩展设置里「允许用户脚本」已打开(Edge/Chrome 新版默认关闭);③ 按 F5 刷新；④ 跑一次 `npm run detect` 看本机是否真的装上了油猴。

**Q: 视频不自动播放?**
A: 浏览器禁止网页自动放声音。在页面上随便点一下鼠标,之后全程自动(脚本已静音,不会吵)。

**Q: 弹出"微信扫码验证"?**
A: 这是学习通的人工验证,任何脚本都过不了。**本人扫码**,扫完脚本自动继续。

**Q: 提示"今日视频任务点完成数已达上限"?**
A: 学习通平台每日限制(不是脚本限制),今天视频不计分了,明天恢复;学习检测不受影响。

**Q: 测验显示"未查到答案"?**
A: 检查 AI Key 是否配置并勾选了 AI 答题。冷门题也可能答不上,脚本会自动暂存不提交(不会乱交卷)。

**Q: 字体加密是什么?**
A: 学习通把题目文字用自定义字体打乱防抄题。本脚本已内置自动解密(Canvas 字形对比法),无需理会。

**Q: 开着梯子(全局代理)时 AI 答题全部失败,日志提示"未查到答案"?**
A: DeepSeek / MiniMax / 智谱等都是**境内服务**。全局代理会把 API 请求劫持到境外节点,节点连国内接口直接失败(学习通有直连白名单所以正常)。解决:① 刷课期间退出梯子(最省事);② 或梯子切**规则模式**,并把所用平台的 API 域名(如 `api.deepseek.com`、`api.minimaxi.com`、`open.bigmodel.cn`)加入**直连白名单**。

**Q: 怎么更新脚本?**
A: 油猴管理面板 → 设置 → 「脚本更新间隔」设为最短。脚本自身每 5 分钟检查一次 `version.json`，**只有远端版本严格更高**才刷新页面；连续更新失败会冷却 6 小时，避免无限刷新。发版只需改 `src/00-meta.txt` 的 `@version` 再 `npm run build`，`version.json` 会自动同步。

**Q: 考试能用吗?**
A: **不建议,风险极高。** 本脚本不包含考试页功能,也请不要在考试时使用。

### v1.5.2 — 弹窗式判分识别 + 假重做入口过滤

- **弹窗式判分**:有些节点的判分不是分数页,而是只弹一句「未达及格线,请重做」——页面上既没有百分比,也没有对勾叉号,弹窗还挡着题目区。旧版本在这种情况下读不到判分,直接当成「此节点不支持重复提交」放弃,错题永远没机会修。现在只要识别到这类文案就**先点掉弹窗**(确定/确认/知道了),再重读判分;重读仍无百分比时按「未达及格线」处理,照常修错题、点重做
- **弹窗文案不误当按钮**:「请重做」这段提示文字长度很短,老逻辑会把它当成「重做」按钮点下去,弹窗没关、重做计数却白涨一次。现在弹窗内的非按钮元素一律不认,只有真正的按钮/链接才算重做入口
- **隐藏的重做按钮不再误点**:判分后仍 `display:none / visibility:hidden` 的重做按钮会被跳过,避免点了没反应却已消耗一次重做额度
- 新增模拟页与用例:只弹「未达及格线」、无分数无对错图标的判分页,`test:accuracy` 22/22、`test` 13/13 全绿

### v1.5.1 — 提交回执校验 + 错题判定补强 + 切章收尾

- **提交回执校验(提交判定)**:点完提交按钮不再直接当成功 —— 立刻回读页面,确认已进入「已提交 / 结果页 / 出现重做入口」;若仍停在作答状态(确认弹窗没点、按钮无响应),自动再点一次并尝试点「确认提交 / 确定」,两次都失败就判本次没交上去、记入「未提交」栏,不再白等 25 秒判分后被误当成「此节点不支持重复提交」
- **错题判定补强(准确率判定)**:判分页只给「我的答案 / 正确答案」两行字、没有对勾叉号也不给分数的版本,现在直接文本比对判对错,不再因「读不到标记」被当成无错题或全军覆没
- **无错题即全对短路**:读准确率时先看错的题数,错题为 0 直接进下一节点,不写错题本、不点重做;有错题则只把判错的题单独重问 AI,其余题原样保留后再点重做
- **切章收尾**:找不到「下一章」按钮即判定已到课程最后一个章节并结束自动切换(不再重试 3 次空转刷日志);切章成功后多等 1.2 秒复核章节指纹,避免「闪一下又回到原章节」被误判为切换成功
- 端到端用例补 2 条(提交回执、最后一章不再空转),`test` 13/13、`test:accuracy` 17/17 全绿

### v1.5.0 — 提交语义重构:填充率 100% + 提交后准确率

- **填充率取代正确率**:面板原来的「正确率阈值」实为填充率(已填题数/总题数),现改名并**固定 100% 不可修改** —— 只要有一题没填上答案就不交卷,不再出现「填了 60% 就交白卷」的亏
- **提交后准确率检测**:新增「准确率阈值」(默认 90%),仅对**可重复提交**的节点生效 —— 提交后读平台判分,达标进下一节点;不达标时挑出判错的题**单独再问一遍 AI**、写错题本、自动点「重做」重来

### v1.4.4 — DeepSeek 新输入条发送失败

- **现象**：题目已经填进 DeepSeek 输入框，但发不出去，脚本随后判「无答案」
- **原因**：DeepSeek 换成受控输入条（textarea + 无文字的圆形图标发送键）。只改 DOM 值不更新框架状态，发送键始终置灰、回车也被忽略
- **修法**：填充改走浏览器编辑管线（`execCommand('insertText')`，事件可信）；发送时跳过置灰控件、优先主色圆钮、补 pointer 序列；全失败再逐字符重填 + 回车兜底
- 探针新增 `dis` 字段，可远程判断发送键是否置灰；新增 `/ai-ds` 模拟页与反证测试，已并入 `test:all`

### v1.4.3 — 故障提示修正

- **中转服务（exe 黑窗口）被关掉时**，不再误报「等网页 AI 页面就绪 / 桥不在线」，而是直接提示「双击刷课助手 exe 并保持窗口开着」，并立即停止等待（原来会空等 90 秒，让人以为 AI 页有问题）
- 答题等待期间中转服务被关闭同样立即中止并给出对应指引

### v1.4.2 — 暂停/切页修复

- **暂停即时生效**：点 ⏸ 会先把页面里真正在跑的 `video/audio` 停住（递归同源 iframe），再置暂停标志；视频、音频、答题循环 2 秒内收手，不再是"点了暂停视频还在播"
- **运行时长暂停冻结**：改成累计口径（`elapsedMs` + 本次启动时刻），暂停即结算，数字不再继续涨；恢复后从新起点计
- **恢复不用刷新**：点 ▶ 主动按当前进度重跑一轮（视频从断点继续）
- **手动切章节/课程不再卡死**：扫描加 1.2 秒稳定判定（避开 `about:blank` 中间态），确认切页后旧一轮作废、新页面自动重扫；所有等待都带取消条件，播放器失效会自行退出
- 排障钩子 `__cxRunState()`：面板页控制台可查轮次令牌/运行状态

### v1.4.1 — 长时间刷课后无法答题

- 根因是浏览器对**后台标签页定时器的强节流**（约 1 次/分钟）：桥的心跳与答题采样同时断档，被误判离线
- 桥 **1.3.0** 把时钟搬进 Web Worker（不受后台节流），心跳/派题/采样全部由 Worker tick 驱动；CSP 拦 Worker 时自动退回原生定时器
- 中转在线窗口 10s → 30s；主脚本发现桥离线时弹窗后轮询 15s 再放弃
